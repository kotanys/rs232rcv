# Протокол передачи данных

## Параметры
- *n*
  Количество бит данных в пакете.
- *f*
  Частота внешнего тактового сигнала.
- *ν*
  Baud rate входящего сигнала.
- *stop_bits*
  Ожидаемое количество стоп бит. Должно не превышать реальное количество стоп бит.
- *M_timeout_log2*
  Влияет на частоту необходимости перекалибровки. См. ниже.

Отношение *f/ν* должно быть в интервале \[32; 240\].
| ν (бод) / f (КГц) | 500   | 1000  | 1500  | 2000  |
|-------------------|-------|-------|-------|-------|
| 9600              | 52,08 | 104,17| 156,25| 208,33|
| 28800             | 17,36 | 34,72 | 52,08 | 69,44 |
| 38400             | 13,02 | 26,04 | 39,06 | 52,08 |
| 57600             | 8,68  | 17,36 | 26,04 | 34,72 |
| 115200            | 4,34  | 8,68  | 13,02 | 17,36 |

## Протокол

Стандарт RS-232. 
- Baud rate 9600..115200 бод (см. таблицу выше для определения тактовой частоты).
- Количество стоп бит ≤ *stop_bits*.
- Длина пакета = *n* бит.
- No parity.

### Калибровка

Первый пакет калибровочный, все его биты данных — единицы.

> [!WARNING]
> Описанное ниже не реализовано.

В случае отсутствия пакетов в периоде *2^(M_timeout_log2)\*M* требуется заново отправить калибровочный пакет.
Устройство сигнализирует об этом путём отправки RS-232 пакета по TX линии с параметрами:

- Baud rate 9600 бод.
- Количество стоп бит = 2.
- Длина пакета = 8 бит.
- No parity.

и со значением 0x10101010
